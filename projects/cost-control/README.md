# CostGuard - AI 成本控制系统

> 让 AI 开发者/小团队清楚知道每个 Agent 的成本，快速发现异常消耗，超支自动止损。

> **免责声明**：成本仅供参考，真实成本请依据各平台订阅使用量计算。我们仅提供尽可能接近真实的毛估统计。

## 🎯 核心功能

- **成本监控** - 清楚知道每个 Agent 花了多少钱
- **异常预警** - 快速发现异常消耗（7 天平均值×2）
- **自动止损** - 超支自动暂停 API（核心差异化）
- **新手引导** - 10 分钟快速上手

## 🚀 快速开始

### Web 版（推荐小白）

```bash
cd cost-control/web
npm install
npm start
# 打开 http://localhost:3004
```

### CLI 版（高级用户）

```bash
npm install -g cost-control
```

### 初始化

```bash
cost-control init
```

### 查看成本

```bash
cost-control dashboard
```

### 设置预算

```bash
cost-control budget set 100
```

### 查看异常

```bash
cost-control alert
```

### 暂停/恢复

```bash
cost-control stop <agent-id>
cost-control start <agent-id>
```

### 新手引导

```bash
cost-control guide
```
